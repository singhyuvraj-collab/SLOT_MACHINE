# 🎰 SLOT MACHINE

## 📌 Project Statement

**SLOT MACHINE** is a simple Python-based interactive game where the user deposits money and spins a slot machine to win rewards based on randomly generated symbols.

The project is designed to demonstrate basic Python programming concepts such as **loops, conditional statements, functions, lists, dictionaries, user input, and random selection**.

---

## 🎯 Objective

The main objective of this project is to develop a simple and interactive slot machine game that:

* Accepts the player's name and deposit amount.
* Validates the deposited amount.
* Randomly generates three slot machine symbols.
* Calculates rewards based on matching symbols.
* Updates the player's balance after every spin.
* Allows the player to play up to a fixed number of spins.
* Displays a final game summary.

---

## 📝 Problem Statement

Design and develop a Python-based slot machine game that allows a user to deposit money and play a limited number of spins.

The program should randomly generate three symbols for every spin and calculate the reward according to the combination of symbols obtained. The player's balance should be updated after every spin, and the game should end when the player runs out of sufficient balance, reaches the maximum number of spins, or chooses to stop.

---

## ⚙️ How the Game Works

1. The program asks the user to enter their name.
2. The user enters the amount of money they want to deposit.
3. The program checks whether the deposit is within the allowed limits.
4. Each spin costs **20**.
5. Three symbols are randomly selected.
6. The program checks the combination of the three symbols.
7. A reward is calculated if one or more symbols match.
8. The player's balance is updated.
9. The player can choose whether to spin again.
10. The game ends when the player stops, does not have enough money, or reaches the maximum number of spins.
